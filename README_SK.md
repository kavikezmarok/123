# Letenky Monitor – oprava Playwright Driver not found

Táto verzia opravuje chybu `Microsoft.Playwright.PlaywrightException: Driver not found`.

Aplikácia sa publikuje ako celý priečinok, nie ako jeden EXE. Po stiahnutí artifactu ponechaj všetky súbory a priečinky spolu.

Spúšťaj `LetenkyMonitor.exe`. Vedľa neho musia zostať DLL súbory, `.playwright` a `pw-browsers`.
